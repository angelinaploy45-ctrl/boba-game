# Boba Cat Catcher 🐱🧋

A fun and interactive web-based mini-game where you control a cute cat trying to catch as many boba (bubble tea pearls) as possible while avoiding sour limes! As you score more points, the game levels up, increasing the speed and challenge.

## 🎮 How to Play
- **Move Left & Right:** Use your keyboard's ⬅️ (Left Arrow) and ➡️ (Right Arrow) keys to move the cat across the screen.
- **Catch Boba (+10 Points):** Catch the regular brown boba pearls to increase your score.
- **Catch Golden Boba! (+50 Points):** Look out for the rare glowing golden boba for a massive score boost!
- **Avoid Limes (-15 Points):** Dodging the green limes is crucial, as they will deduct your hard-earned points.
- **Time Limit:** You have 60 seconds to get the highest score possible.

## ✨ Features
- **Dynamic Fullscreen Space:** The game automatically adjusts to your browser window size, giving you a wide playing field.
- **Leveling System:** For every 100 points, you progress to the next level. The falling items increase in speed, challenging your reflexes!
- **Floating Text Animations:** Visual feedback (+10, +50, -15) appears right where you catch an item.
- **Responsive UI:** Clean overlay screens for Start Game and Game Over states.

## 🛠️ Technology Stack
This game is built entirely using standard web technologies (No frameworks needed!):
- **HTML5:** For structuring the game container and UI elements.
- **CSS3:** For styling, positioning, and visual effects.
- **Vanilla JavaScript:** For the core game loop, logic, item physics, and collision detection.

## 🚀 How to Run Locally
1. Download or clone this repository to your computer.
2. Open the folder containing the game files.
3. Simply double-click on `index.html` to open it in any web browser (Chrome, Edge, Safari, etc.).
4. Click "Start Game" and enjoy!
